# FAST · CRAFTS 漂移扫描三维演示

FAST（500 米口径球面射电望远镜）19 波束 CRAFTS 漂移扫描的可交互三维演示。
浏览器直接打开 `index.html` 即可，**纯静态、无外部依赖、不发任何网络请求**（three.js 已随仓库分发）。

在线版：https://liufei27.github.io/FAST_CRAFTS_Scan/

## 看点

- **望远镜本体**：500 m 基准球面、300 m 工作抛物面（f = 138.63 m）、馈源舱、六塔索缆；
  「主动变形」滑块可从纯球面连续过渡到工作抛物面。
- **19 束指向**：实测中心坐标（Jiang et al. 2020）、CRAFTS 的 23.4° 阵列旋转、按频率变化的束宽。
- **漂移扫描**：天空从天顶附近穿过固定的 19 束；「扫描拖尾 5h」显示每束过去 5 小时扫过的天区并渐隐。
- **天球**：赤道网格、可观测赤纬边界（−14.4° ~ +65.6°，对应 40° 天顶角）、
  4094 颗 ATNF 脉冲星与 222 颗 CRAFTS 脉冲星。
- 五个视角预设：全景 / 馈源舱仰视 / 天球俯视 / 剖面 / 轴向俯视。

**说明**：本公开版未包含 19 束的实测二维方向图，波束以高斯模型近似
（FWHM 2.9′，随频率按 1/ν 缩放）。因此「波束响应分布」面板与「穿越光变曲线」
在公开版中不提供。

## 坐标与近似

- 使用 J2000 星表 + 当日岁差改正；章动、光行差、大气折射未建模（合计 < 20″）。
- 19 束的真实角跨度只有 25′，相对 500 m 望远镜与 3 km 天球几乎不可见，
  故引入「角尺度 k」（×1 真实 / ×40 示意），相对几何保持不变。
- 地形、塔基高程、面板与索网拓扑均为示意。
